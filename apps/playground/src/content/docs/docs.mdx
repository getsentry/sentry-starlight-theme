## Sandbox Expectations

- Treat the playground as the canonical visual sandbox for this package.
- Add a fixture before changing shared visual behavior.
- Keep site-specific styling in consuming projects, but reproduce reusable patterns here.
- Verify `.md` output whenever changing rendered HTML to Markdown conversion.
