## Checks

- Desktop sidebar active states remain visible.
- Mobile navigation opens without layout overlap.
- Right-sidebar table of contents and Markdown action stay aligned.
- Code blocks keep line breaks, indentation, and language labels.
- Card grids collapse cleanly on narrow viewports.
- Key/value lists remain readable in HTML and generated Markdown.
- Generated Markdown routes preserve useful navigation without duplicating headings.

## Commands

```sh
pnpm dev
pnpm astro:check
pnpm playground:build
```
